# Public salary ranges from 266 companies (open dataset)

**8,039 job postings that state a pay range**, harvested from the public job boards of 266 companies, normalised to annual USD. Snapshot: **2026-10-24**.

This repository is the raw data + licence for the dataset published at
<https://sjdfi0wjvosdju9.github.io/salary-data.html>. It is refreshed weekly from the same pipeline.

## What is in here

| File | Rows | Size | What it is |
| --- | ---: | ---: | --- |
| `data/salary-ranges-full.csv` | 8,039 | ~1.7 MB | one row per posting that publishes a range |
| `data/publication-by-company.csv` | 146 | 4 KB | per-company disclosure rate (same denominator as numerator) |
| `data/freshness.json` | — | 10 KB | how old the postings are, by board and company |
| `data/lookup.json` | 152 | 37 KB | per-company medians, ready for a UI |

Columns: `company, ats, title, location, remote, role_family, salary_usd_low, salary_usd_high, salary_usd_mid, posted_at, url, salary_currency, salary_local_low, salary_local_high`.

## Honest limits

- These are **published** ranges, not what anyone was actually paid.
- About 57% of postings publish nothing; they are absent, not zero.
- Level bands are common: when a posting lists several (e.g. L4 and L5), the **first band** is used.
- Implausible values (under $5k or over $5M a year after normalisation) are **dropped entirely** rather than clamped, so the tail is missing rather than wrong.
- Currency conversion uses a daily rate; the original local-currency range is kept in `salary_local_*`.
